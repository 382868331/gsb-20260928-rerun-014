# 科研计算笔记本

带依赖计算单元的实验笔记本：增量重算、错误失效定位、实验快照与参数支线、重开持久化。

## 运行

```bash
npm install
npm run dev      # 开发
npm test         # vitest：菱形依赖 / 成环 / 中途报错 / 版本隔离 / 重开持久化
npm run build    # 类型检查 + 产物构建
```

## 模型

- 单元分 `input`（数值输入）与 `formula`（表达式，可按名称引用其他单元，如 `a + b * 2`）。
- `src/core/evaluator.ts`：安全算术求值（+ - * / % ^、括号、单元名引用；除零、缺名等抛错）。
- `src/core/engine.ts`：Kahn 拓扑排序决定执行次序；菱形汇点只执行一次。
  - 增量：输入变化时用反向依赖求受影响下游，未受影响单元在定义指纹（revision）一致时沿用结果。
  - 失败：被重算单元先清空旧值，失败时 `status=error,value=null`，上一版成功值不会冒充当前值；下游标记“上游失败”并跳过。
  - 成环：拓扑排序定位环上单元，全部置错且不产出数值；另含重名、自引用、引用不存在等定义错误定位。
- `src/core/storage.ts`：实验快照与支线使用深拷贝，支线间完全隔离；`localStorage` 保存“输入定义 + 结果 + revision + 执行次序”的完整对应关系，重开后可复原，而不仅是最后显示的数字。
- `src/store/useNotebook.ts`：zustand 状态，编辑即增量重算并持久化。

## 页面

- `ExperimentList`：新建 / 打开 / 分叉 / 删除实验。
- `NotebookPage`：单元表格，展示执行次序、表达式、当前结果与错误定位，可保存快照或分出支线。
- `UnitEditor`：编辑单元名、输入或表达式，实时显示成功值或失效原因。
