# 科研计算笔记本

带依赖的计算单元实验环境：单元可引用前面或其他单元的结果，编辑输入后只重算受影响的下游；执行失败时旧成功值立即作废；支持保存完整实验快照并从中分出参数支线，重开浏览器后输入与结果的对应关系仍然保留。

## 运行

```bash
cd frontend
npm install        # 仓库已预装 node_modules 时可跳过
npm run dev        # 开发服务器
npm test           # vitest 单元/集成测试
npm run build      # tsc 类型检查 + 生产构建
```

## 核心设计

- `src/compute/evaluator.ts`：手写的安全表达式解析器（词法 + 递归下降），不使用 `eval`；支持 `+ - * / % ^`、括号、一元负号、`sqrt/abs/round/floor/ceil/exp/ln/log/log2/sin/cos/tan/pow/min/max` 与常量 `pi/e`，并能提取变量引用。
- `src/compute/graph.ts`：依据单元名构建依赖图，检测重名/非法名/引用缺失，Tarjan SCC 检测引用成环，Kahn 稳定拓扑排序，传递下游闭包用于增量传播。
- `src/compute/engine.ts`：
  - `runAll` 按拓扑序全量执行；环上单元报“依赖成环”并给出形如 `b → c → b` 的路径；上游错误的下游标记为 `skipped`，错误可定位到具体单元。
  - `runIncremental` 只重算变更单元及其受影响下游；未受影响单元必须指纹一致才复用结果，指纹失配强制重算；失败写入 `value=null` 的错误结果，上一版成功值不会被继续当作当前值。
  - `markStale` 在编辑后、重算前立即把受影响下游标记为 `stale`，界面不会再展示旧数字为当前结果。
  - 每个结果带 `fingerprint = type + name + expr`，持久化重开后仍能判断结果是否对应当前输入。
- `src/services/experimentStore.ts`：实验快照（单元 + 结果整体保存于 `localStorage`，可注入内存存储用于测试）、深拷贝支线、父子谱系；支线修改不影响父实验。
- `src/hooks/useNotebookEditor.ts`：编辑后立即作废旧值、120ms 合并增量重算、400ms 防抖自动保存；StrictMode 下通过实例纪元防止已卸载实例的过期回调覆盖新状态。

## 页面

- 实验列表：新建/删除实验，从任意实验“分出支线”。
- 编辑页：添加输入/公式单元、改名、改表达式、排序、删除；显示每个单元的成功值或错误原因、支线谱系；支持“全部重算”“保存快照”“分出参数支线”。

## 关键场景验证（见 `src/test`）

- 菱形依赖 `a→b→d, a→c→d` 的计算次序与单分支增量重算。
- 双节点环、自环的错误定位与路径提示，打破环后增量恢复。
- 除零/函数非法输入的中途报错定位、下游跳过、旧成功值失效。
- 支线深拷贝版本隔离；刷新重开后输入与结果一一对应，失败快照重开仍为失败。
