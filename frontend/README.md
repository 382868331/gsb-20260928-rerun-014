# 科研计算笔记本

带依赖计算单元的实验笔记本：引用环精确隔离、增量重算、参数情景并排比较、公式版本化预览与逐情景接受、重开持久化。

## 运行

```bash
npm install
npm run dev      # 开发
npm test         # vitest：环隔离/断环恢复、情景隔离、预览接受、结果仓共享、持久化与 v1 迁移
npm run build    # 类型检查 + 产物构建
```

## 模型

- 单元分 `input`（数值输入，含共享默认值）与 `formula`（共享表达式，带 `version`）。
- `src/core/evaluator.ts`：安全算术求值（+ - * / % ^、括号、单元名引用；除零、缺名等抛错）。
- `src/core/engine.ts`：
  - Tarjan 强连通分量找出全部引用环；环成员置 `cycle` 错误且不产出数值。
  - 环的下游沿反向依赖传播标记为 `upstream` 阻塞；**独立常量与不依赖环的分支照常计算**。
  - 可执行部分按 Kahn 拓扑序执行，菱形汇点只执行一次；执行次序只含可执行单元。
  - 增量：编辑点下游 + 结构受阻单元 + 上一轮非成功单元进入重算集。**断开环后只恢复环与被阻塞部分**，未受影响成功结果沿用。
  - 沿用旧结果要求 `revision` 与当前定义一致（输入文本或公式版本+内容指纹），旧成功值不可能误接到新输入。
- `src/core/scenarios.ts`：参数情景。
  - 情景只存参数覆盖（`params`）与自己的 `results` / `pending`；公式定义在实验内共享，每个公式保留完整版本历史（`revisions`），情景记录自己**已接受的版本号**（`acceptedFormulaVersions`）。
  - 正式计算把共享公式**物化到该情景已接受的版本**：未接受改版的情景，改参数、全部重算、保存重开都仍按旧公式出结果；接受状态、参与计算的公式与结果来源三者一致。预览（`effectiveUnits(..., "pending")`）只在内存/暂存区用最新表达式，绝不回写正式结果。
  - `resultKey` 内容寻址：input 看输入文本，formula 看版本+表达式+全部上游结果键；结果记录存放在实验级 `resultStore` 并按情景引用计数，相同结果跨情景共享，删除情景只解除引用，不破坏其他情景沿用的成功记录。
  - 修改共享公式：版本号 +1 并追加一条 `revisions`，每个情景以**自己的已接受版本为基线**生成 `pending` 预览（`pn:` 前缀暂存键），说明相对该情景基线的改变；不同情景可停留在不同已接受版本，再分别预览更晚版本。可逐情景「接受新结果」（转正为当前版本）或「保持旧版/放弃预览」（继续留在基线）。一个版本在某情景形成引用环不影响其他情景，断环版本同样只影响采用它的情景；内容键带版本号，部分接受后保存重开也不会把不同版本的成功/失败记录混接。
  - 派生情景明确继承派生时刻的参数、已接受公式版本与已接受结果（引用结果仓同一批记录）；父情景之后接受更新不会改变子情景，子情景需自行预览并接受。
- `src/core/storage.ts`：`localStorage` v2 保存共享定义（含公式版本历史）、各情景参数/结果/已接受版本、结果仓与执行次序，重开后可追溯每个结果对应的参数与公式版本；`normalizeExperiment` 为旧数据补齐版本历史；并自动把 v1 单情景数据迁移为默认情景。
- `src/store/useNotebook.ts`：zustand 状态，参数编辑只重算当前情景（按其已接受公式版本），公式编辑为所有情景按各自基线生成预览。

## 页面

- `ExperimentList`：新建 / 打开 / 分叉 / 删除实验，显示情景数与待处理改版数。
- `NotebookPage`：首列为共享单元与公式，其后每个情景一列并排比较；参数就地编辑，单元格展示当前结果、环/阻塞定位与待接受预览，列底部可接受或保持旧版。
- `UnitEditor`：编辑共享公式（改版提示影响全部情景）、名称、备注与输入默认值，显示当前情景的已接受结果与预览。
